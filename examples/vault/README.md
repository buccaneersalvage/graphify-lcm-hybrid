# Example vault layout

Copy this shape into `vault/` at the memory-tree root (or just start writing there). Graphify indexes the markdown. Hermes-LCM does not.

```
vault/
  work/
  ops/
  notes/
  hermes/          export-only — LCM summary index
```

Filename: `YYYY-MM-DD_short-slug.md`. One incident or rule per file.

`vault/hermes/` is regenerable. Do not hand-write durable facts there.
